# Approved-reference glass plates

These are complete photographic weather-and-glass plates edited with built-in imagegen from the user-provided approved reference. There is no text, icon or internal divider baked into these assets. Do not overlay procedural bevels, borders, highlights, or white fill on them.

- cloud: original cloudy daytime master with foreground content removed.
- clear, rain, snow, thunder, fog: weather edits using the same original glass reference.
- night: clear/partly-cloudy night.
- cloud-night, rain-night, snow-night, fog-night: dedicated night weather plates.

The renderer selects a plate and overlays dynamic weather data and shared vector icons. Full prompts are in docs/generation-prompts.json. Image editing does not guarantee pixel-identical preservation; visual acceptance is by user review. Original generated outputs are retained separately outside this repository.
