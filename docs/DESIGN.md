# 原图母版版本

用户明确选择原图效果；前两次程序模拟玻璃边缘的方案已撤下。当前版本以用户原始图为编辑目标，用内置 imagegen 移除文字和图标、保留玻璃，再按相同参考分别更换天气场景。

## 渲染约定

- assets/glass-plates/ 保存 11 张不含文字、图标、内部隔线的完整天气玻璃底版。
- 原图中的玻璃轮廓、反光、透光效果直接来自编辑后的素材。代码不再叠加白边、渐变倒角、边缘光或程序折射。
- src/render.py 仅按天气选择底版、缩放至统一画布，再叠加地点、时间、天气数据、图标与细隔线。
- 七个基础场景：cloud、clear、rain、snow、thunder、fog、night。另有 cloud-night、rain-night、snow-night、fog-night；雷暴本身采用深色底版。
- 图标和数据覆盖 60 个 WeatherAPI 代码。多个强度共享底版，依靠具体图标和文案区分。
- PNG 使用连续自然灰阶。没有预先量化、抖动或二值化。
- 夜间由 WeatherAPI is_day 自动选择浅色文字和浅色图标（灰度 246），不添加描边或阴影，适应 400×300 的低分辨率显示。主图标、指标图标、预报图标使用同一规则；不改变底版或玻璃反光。图标库提供形状，最终前景色由渲染器统一应用。

## 来源与审核

玻璃素材由内置 imagegen 直接编辑用户提供的原图；提示词在 generation-prompts.json。母版方法更接近选定的视觉目标，但生成编辑并非对每个像素的锁定复制，最终仍以用户对画面效果的确认作为验收。

图标为本项目原创矢量；字体为 Inter 与 Noto Sans SC，附各自 OFL。WeatherAPI 条件代码快照为 2026-10-16 的官方数据。生成的天气背景不是实时天气照片。预览为示例数据。

原图与中英文动态叠字对照见 preview/master-comparison.png。本项目仅生成图片，不连接设备。
